# authresults
A zero-dependency, pure-Python, fully typed parser of one `Authentication-Results` value (and, recommended, one `ARC-Authentication-Results` value) into immutable objects. No DNS, no verification, no message parsing.

**Status:** pre-alpha, not yet released. The parser is not implemented yet.

- Requires Python 3.11 or later; no runtime dependencies.
